Как установить на Mac
  1. Скачайте ZIP и откройте его в папке «Загрузки».
  2. Перетащите BREAKPOINT.app в «Программы».
  3. Запустите игру из папки «Программы».

Для тестового выпуска macOS может запросить разовое подтверждение. После первой попытки запуска откройте «Системные настройки → Конфиденциальность и безопасность» и выберите «Всё равно открыть» для BREAKPOINT. Инструкция Apple

Новые версии появляются в главном меню игры, во вкладке «Обновления».
