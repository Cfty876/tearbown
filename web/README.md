# Воксельный снос в браузере

Папка `public/` содержит браузерную сборку Godot 4.7.2 с воксельным ядром WebAssembly. Сайт открывается на ПК и на телефоне. На сенсорном экране левый джойстик отвечает за ходьбу, правая часть экрана за обзор. Кнопки открывают снаряжение, стреляют, выполняют действие, прыгают и ставят игру на паузу. В машине кнопка прыжка работает как ручник. Графический пресет можно менять прямо в меню паузы на телефоне.

## Локальный запуск

Из этой папки запусти `npm run dev` и открой `http://127.0.0.1:8080`. Локальный сервер держит комнаты в памяти и подходит для проверки двумя окнами. Открывай игру через сервер, чтобы браузер разрешил загрузку WebAssembly.

## Публикация в Vercel

1. При импорте GitHub-репозитория указать **Root Directory** `web`. Пресет **Other**, каталог вывода **public**. Готовая сборка лежит в `public/`, функцию комнат содержит `api/room.js`.
2. Подключить Upstash Redis через Marketplace или задать `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` в настройках Vercel. Функция также читает `KV_REST_API_URL` и `KV_REST_API_TOKEN`, если интеграция добавила переменные с этими именами. После изменения переменных нужно перепубликовать проект.
3. Открыть сайт, нажать **Открыть игру**, затем **Прятки вдвоём — по коду**. Первый игрок создаёт комнату, второй открывает тот же сайт и вводит код или открывает ссылку-приглашение.
4. Если устройства за сетями, где WebRTC не может соединиться напрямую, подключить coturn с TURN REST и задать `TURN_URLS` (адреса через запятую) и `TURN_SECRET`. Функция выдаёт временные учётные данные. В конфигурации Vercel сохранены заголовки COOP/COEP для WebAssembly.

## Режимы и ограничения

- **Лёгкая карта** открывает компактную одиночную песочницу с машиной, семью инструментами и разрушаемыми укрытиями. Пригород и полигон остаются в меню. В браузерном пригороде меньше деревьев и припаркованных машин.
- Для пряток используется компактная арена с укрытиями. Хост управляет таймером, сменой ролей и общим состоянием разрушений. Инструменты включаются в фазе поиска.
- Передача позиций идёт через WebRTC без ожидания повторной доставки устаревшего пакета. Изменения вокселей и события раунда идут надёжным каналом. Звук и отдача инструментов запускаются на устройстве игрока сразу, а разрушения рассчитывает хост. Скорость зависит от устройства, сцены и сети.
- В Web используется Compatibility. Дальняя глубина резкости из десктопного рендера недоступна. Эффекты краёв и поворота доступны в настройках. Начальный пресет ограничивает внутреннюю высоту рендера и количество мелких физических обломков, а на телефоне по умолчанию отключает размытие краёв и солнечные лучи.
- В прятках нет транспорта и перетаскивания предметов. В одиночных картах эти действия доступны через кнопку взаимодействия.

## Пересборка

Нужны Godot 4.7.2, шаблон Web с GDExtension и без потоков, Emscripten 4.0.11 и CMake/Ninja. Собери `native/` через toolchain Emscripten, затем запусти из корня исходников `build_web.ps1`, передав `-Godot`, `-Template`, `-Wasm` и путь отдельной папки `-Stage`.
