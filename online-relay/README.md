# Онлайн-комнаты BREAKPOINT

Из меню «Создать комнату» выберите «Онлайн». Передайте игрокам код вида `BP-A1B2-C3D4`. В локальном режиме игра использует ENet на UDP 47840. Онлайн-клиенты используют WSS, им не нужно пробрасывать порты. Матч рассчитывает компьютер создателя, а сервер передаёт сообщения между участниками комнаты. Отключение создателя завершает матч.

## Проверка на одном ПК

1. Установите Node.js 22 или новее.
2. Выполните `npm ci`, затем `npm start` в папке ретранслятора.
3. В двух копиях игры укажите `ws://127.0.0.1:8787/rooms`. Создайте комнату, скопируйте код и войдите во второй копии. Убедитесь, что её карта, состав и правила совпадают с настройками хозяина.
4. Выполните `npm test` для проверки протокола комнат.

## Развёртывание для скачиваемой игры

1. Направьте DNS-запись отдельного поддомена на VPS. На сервере подготовьте Docker Compose и Caddy. Скопируйте эту папку и запустите `docker compose up -d --build`.
2. Добавьте блок ниже в Caddyfile, подставьте свой домен, откройте TCP 80 и 443 для Caddy и перезагрузите его. Ретранслятор опубликован только на loopback-интерфейсе VPS.
   ```caddy
   rooms.example.org {
       reverse_proxy 127.0.0.1:8787
   }
   ```
3. Проверьте `https://<ваш-домен>/healthz`, затем создайте матч между двумя компьютерами в разных сетях через `wss://<ваш-домен>/rooms`.
4. Скопируйте `online.cfg.example` в папку рядом с BREAKPOINT.exe под именем `online.cfg` и укажите свой WSS-адрес. В свежей установке адрес появится автоматически. Также игрок может изменить адрес в меню, а администратор может переопределить его переменной среды `BREAKPOINT_RELAY_URL`.

Один экземпляр хранит комнаты в памяти. Перезапуск сервера завершает открытые комнаты. Количество подключений ограничено 512, количество комнат 256. Это защитные лимиты, пропускную способность под нагрузкой измеряйте отдельно с настоящими игровыми пакетами и клиентами из разных сетей. Для пилотного выпуска следите за памятью, нагрузкой на процессор, задержками и переподключениями. Добавляйте отдельные региональные серверы по результатам замеров, сохраняя выбранный сервер для каждого приглашения.
