# BREAKPOINT

Воксельная песочница с разрушаемыми картами и прятками по коду комнаты. Доступны «Дворы Заречья», «Полигон» и «Школа № 120». В браузерной версии для пряток используется компактная «Арена».

## Запуск

- **Windows x64.** Распакуйте архив целиком и запустите `BREAKPOINT.exe` рядом с библиотеками DLL.
- **macOS.** Распакуйте подписанный универсальный архив и перенесите `BREAKPOINT.app` в «Программы».
- **Браузер.** Запустите игру на странице `/play/`. Онлайн-комнаты доступны после настройки WSS-ретранслятора.

## Сборка

Исходник Godot находится в `game/`. Нативное ядро `voxcore` — в `native/`. Версия движка 4.7.2. Сборка ядра использует [godot-cpp](https://github.com/godotengine/godot-cpp) в `tools/godot-cpp` на коммите `cedbd9e71b24eb2898b28867c5faf6114da9e5e2`.

- **Windows.** Соберите `voxcore.dll` с помощью `build_native.bat`. Подготовьте отдельный проект командой `python tools/stage_release.py windows <пустая-папка>`, положите DLL в его `bin/`, импортируйте его в Godot и экспортируйте пресетом Windows Desktop. NobodyWho опционален и нужен для локальной модели диалогов. Укажите `--relay wss://ваш-домен/rooms` при подготовке проекта, чтобы адрес автоматически подставлялся после установки.
- **macOS.** С Xcode Command Line Tools, Python 3.9+, CMake и шаблонами Godot задайте `GODOT_BIN` и выполните `bash build_macos.sh <пустая-папка>`. Скрипт собирает `arm64` и `x86_64` в одной библиотеке, экспортирует `.app` и проверяет обе архитектуры. При наличии Developer ID задайте `BREAKPOINT_CODESIGN_ID` и имя сохранённого профиля `BREAKPOINT_NOTARY_PROFILE`, чтобы подписать приложение и заверить его через Apple. Без них создаётся тестовый архив.
- **Web и Vercel.** [Настройка сайта и сборки](web/README.md). [Инструкция для WSS-ретранслятора](online-relay/README.md).

Публичные сборки используют собственные звуки сирены и школьного звонка. Личные записи, тестовые сцены, старые политики обучения и кэш импорта исключены из релизного проекта. Встроенные инструменты разработки доступны при запуске из редактора.
